# Пример программы БК. Формат строки: Тип;Порог;Ёмкость;Мощность;Тпара
# Тпара: 0 = вода дефлегматора вручную на этой строке, 30..100 = держать пар
#   около этой температуры (°C) шаговым регулятором. Датчик пара ставится
#   НАД дефлегматором, в паровой зоне перед холодильником.
# Мощность: первая строка программы с ненулевым напряжением обязана быть
#   АБСОЛЮТНЫМ значением - больше 40 В (регулятор в вольтах) или больше
#   400 Вт (регулятор в ваттах), иначе нагрев в разгоне может незаметно
#   выключиться. 0 в остальных строках - не менять текущее значение.
# Значения мощности в этом примере - вольты; для регулятора в ваттах первая
#   ненулевая мощность должна быть больше 400.
T;78;1;190;70
T;90;2;0;78
T;93;2;0;0
