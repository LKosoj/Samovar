# Выбранные функции Samovaritch

## Цель

Добавить в Samovar только согласованные функции из Samovaritch, сохранив текущие
очереди команд, подтверждение I2C, атомарное сохранение профиля и старое поведение
для пользователей, которые новые настройки не включили.

## Решения

- MPX получает две сохраняемые настройки: нулевое показание АЦП и число отсчётов
  АЦП на 1 мм рт. ст. Дефолты `36.7` и `12.0` сохраняют старую формулу.
- Экспорт пивной программы сохраняет версионированный JSON с программой и
  описанием. Импорт принимает этот формат и старый простой текст. Повреждённый
  JSON не трактуется как старая программа.
- При включённом втором насосе I2C-насос, обнаруженный при старте, обслуживает
  отбор над царгой пастеризации. В строке `H` он выполняет отбор вместо локального
  насоса, в `B/C` работает непрерывно с отдельной скоростью одновременно с
  локальным насосом. Если насос не был обнаружен при старте, второй отбор не
  используется. Одна I2C-команда повторяется до 10 раз; после десяти попыток без
  подтверждения запуск или продолжение завершается явной ошибкой.
- Переключение потока НБК включается отдельной настройкой. Позиция сервопривода
  `0` направляет чистый поток, позиция `1` — загрязнённый. При захлёбе выбирается
  позиция `1`; возврат в `0` происходит после полного завершения восстановительной
  паузы и при остановке режима.
- В setup добавляются подсказки только к существующим и новым настройкам, смысл
  которых подтверждён исходным кодом.
- README описывает Windows-конфигуратор и PlatformIO как основной способ настройки,
  компиляции и прошивки. AGENTS.md и карта кода описывают фактическую блокировку
  файловых операций `/edit`, а не отсутствующий полный запрет на весь процесс.

## Проверка

- Поведенческие smoke-тесты извлекают изменённую логику из исходников и проверяют
  минимум два разных значения или состояния.
- Старые профили V1/V2 мигрируют в новый формат с безопасными значениями новых полей.
- Web-исходники собираются из `data_raw/`, затем проверяются smoke- и браузерными
  тестами через обязательный `playwright-cli`.
- После smoke-тестов последовательно собираются все окружения PlatformIO; затем по
  собранным ELF запускается проверка IRAM обработчика шаговика.
