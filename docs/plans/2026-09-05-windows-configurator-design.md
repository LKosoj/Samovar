# Настройка и прошивка Samovar в Windows

`flash_windows.bat` устанавливает недостающие Python, Tkinter и PlatformIO, затем
запускает локальное приложение `tools/samovar_configurator.py`.

Приложение показывает пользовательские параметры `Samovar_ini.h` в виде полей,
галочек и взаимоисключающих списков. Оно меняет только известные строки и сохраняет
остальной текст заголовка. Плата выбирается из DEVKIT, LILYGO и ESP32S3. Для загрузки
используются существующие окружения PlatformIO: `Samovar` для DEVKIT/LILYGO и
`Samovar_s3` для ESP32S3.

SSID и пароль хранятся в локальном `user_config_override.h`, который не отслеживается
Git. Новая копия создаётся из `user_config_override.example.h`. Встроенные реквизиты
Wi-Fi применяются только тогда, когда в памяти ESP32 ещё нет сохранённой сети.

Кнопки приложения отдельно сохраняют настройки, прошивают устройство, загружают
LittleFS и открывают монитор порта. Перед LittleFS требуется подтверждение. Вывод
PlatformIO построчно показывается в журнале окна; одновременно выполняется одна команда.
Основной журнал растягивается по высоте вместе с главным окном.
Монитор порта открывается в отдельном модальном окне с собственным журналом и кнопкой
остановки; закрытие этого окна также останавливает монитор.
