# Настройка и прошивка Samovar в macOS и Linux

`flash_macos_linux.sh` проверяет Python с Tkinter и PlatformIO, устанавливает
недостающие зависимости и запускает существующее приложение
`tools/samovar_configurator.py`.

В macOS Python и Tkinter устанавливаются через Homebrew. Если Homebrew отсутствует,
скрипт завершается с явной инструкцией, не устанавливая отдельную инфраструктуру
самостоятельно. В Linux поддерживаются `apt`, `dnf` и `pacman`; системные пакеты
устанавливаются через `sudo`, если скрипт запущен не от `root`.

PlatformIO устанавливается официальным `get-platformio.py` в пользовательское
окружение. Скрипт не собирает и не прошивает устройство самостоятельно: эти действия,
загрузка LittleFS и монитор порта остаются кнопками общего Python-конфигуратора.
Основной журнал использует свободную высоту при увеличении главного окна.
Монитор открывается в отдельном модальном окне с большим журналом; его кнопка сначала
останавливает монитор, а после завершения закрывает окно.

macOS может запретить Terminal доступ к проекту, распакованному в `Downloads`. В этом
случае оболочка сообщает `getcwd: cannot access parent directories: Operation not
permitted`, а скрипт не начинает выполняться. Пользовательская инструкция в `README.md`
предлагает перенести проект в домашнюю папку либо разрешить Terminal доступ к
«Загрузкам» в настройках «Конфиденциальность и безопасность» → «Файлы и папки».
