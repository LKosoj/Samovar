Программа дистилляции:
Описание программы дистилляции в текстовом формате для сохранения в облаке:
Программа дистилляции:
  • Тип программы
    T - режим дистилляции по температуре в кубе
    S - режим дистилляции по относительному изменению содержания спирта в кубе
    A - режим дистилляции по абсолютному изменению содержания спирта в кубе
    P - режим дистилляции по абсолютному изменению содержания спирта в паре
    R - режим дистилляции по относительному изменению содержания спирта в паре
  • Значение (зависит от типа программы): температура, абсолютное значение спиртуозности (в °) или для S/R — доля от начальной спиртуозности строго между 0 и 1, границы не включены (1 значило бы «спиртуозность не изменилась» — такая строка завершится мгновенно)
  • Номер ёмкости — переключается не сразу, а в момент, когда сработает условие ЭТОЙ строки (фактически задаёт ёмкость для СЛЕДУЮЩЕЙ строки)
  • Напряжение — тоже применяется в момент срабатывания условия ЭТОЙ строки, а не всё время, пока она активна. 0 — не менять текущее значение регулятора. Если это ПЕРВАЯ строка программы с ненулевым напряжением — она обязана быть абсолютным значением, а не небольшой поправкой (больше 40 В; для регулятора в ваттах — больше 400 Вт), иначе нагрев в разгоне может незаметно выключиться. Пример программы дистилляции:
T;90;1;190
A;40;2;0
P;20;3;0

R;0.30;3;15
