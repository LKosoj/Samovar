Программа БК:
Описание программы БК в текстовом формате для сохранения в облаке:
Программа БК:
  • Тип программы
    T - режим по температуре в кубе
    S - режим по относительному изменению содержания спирта в кубе
    A - режим по абсолютному изменению содержания спирта в кубе
    P - режим по абсолютному изменению содержания спирта в паре
    R - режим по относительному изменению содержания спирта в паре
  • Значение (зависит от типа программы): температура, абсолютное значение спиртуозности (в °) или для S/R — доля от начальной спиртуозности строго между 0 и 1, границы не включены
  • Номер ёмкости — переключается не сразу, а в момент, когда сработает условие ЭТОЙ строки (фактически задаёт ёмкость для СЛЕДУЮЩЕЙ строки)
  • Напряжение — применяется в момент срабатывания условия ЭТОЙ строки. 0 — не менять текущее значение регулятора. Если это ПЕРВАЯ строка программы с ненулевым напряжением — она обязана быть абсолютным значением (больше 40 В; для регулятора в ваттах — больше 400 Вт), иначе нагрев в разгоне может незаметно выключиться. Значения в примере ниже — в вольтах
  • Т пара — уставка охлаждения дефлегматора на этой строке, 0 — вода вручную (насос не трогается автоматикой), 30..100 — держать пар около этой температуры (°C) шаговым регулятором
Пример программы БК (файл program_bk.txt):
T;78;1;190;70
T;90;2;0;78
T;93;2;0;0
